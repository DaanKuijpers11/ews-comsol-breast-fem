2) Automatische postprocess herstellen
Probleem:
- Manual export werkt als de filename handmatig kort wordt ingevuld.
- COMSOL GUI/export lijkt fouten te geven wanneer default export paths of namen te lang worden.
- Automatic postprocess hangt soms of schrijft geen CSVs.

Onderzoek/fix-richting:
- Inspecteer generated postprocess Java en export file paths.
- Zorg dat automatic postprocess altijd korte, expliciete export filenames gebruikt.
- Gebruik kortere submappen/namen voor stage scouts.
- Geen reliance op COMSOL GUI-default export location.
- Global/scalar postprocess moet geen image export of lange surface export doen.
- Full postprocess mag surface exports doen, maar alleen met korte filenames.
- Voeg duidelijke statusregels toe: init_start, load_start, evaluate_start, export_start, done.

Gewenst eindresultaat:
- In een TOML kan postprocess_mode weer aan.
- Na een run verschijnen automatisch compacte CSVs in een voorspelbare outputmap.
- Manual Derived Values blijft fallback, niet de hoofdroute.
