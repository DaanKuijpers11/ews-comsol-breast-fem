# FEBio Runs

This folder collects FEBio-oriented testcase definitions, generated `.feb` files, logs, summaries, and output folders.

Main groups:
- `elipse_lobules_testcases`
  - earlier glandular ellipsoid and Chen-inspired testcase studies
- `overnight_suite`
  - broader FEBio benchmark and comparison runs
- `radial_testcases`
  - adipose radial heterogeneity studies
- `ligth_vs_mid_vd_heavy_cases`
  - load/intensity comparison cases
- `geometry_stage1`
  - new outer-geometry validation cases for the shared FEBio source model

The goal of this grouping is to keep FEBio runs clearly separated from COMSOL cases while preserving older FEBio results and testcase history.
