# Dynamic Realism Branch

This is a parallel COMSOL development branch focused on visible geometric realism while
keeping:

- simple glandular structure
- dynamic motion
- lightweight and interpretable cases

Use this branch for changes that should be easy to see in COMSOL, such as:

- asymmetry
- new chest-support concepts
- ligament layouts

This branch should not replace the main COMSOL stages. It is meant to de-risk and visualize
new realism ideas before promoting them into the heavier pipeline.
