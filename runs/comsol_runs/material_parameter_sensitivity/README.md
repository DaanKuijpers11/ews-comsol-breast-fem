# Material Parameter Sensitivity

This folder contains the old material-test/preflight cases that previously lived under Stage 3. They were moved out because Stage 3 is now reserved for glandular fraction and glandular realism.

## Role

Use this folder only for material parameter justification, calibration notes, or sensitivity comparisons. It should not be treated as a geometry stage.
